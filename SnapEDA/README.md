# SnapEDA RP2040-ZERO Model

Source page:

https://www.snapeda.com/parts/RP2040-ZERO/Waveshare%20Electronics/view-part/

This page is the intended source for the Waveshare `RP2040-ZERO` KiCad symbol, footprint, and 3D model.

Automated download from this environment was blocked by SnapEDA/Cloudflare with HTTP 403, so the SnapEDA model files are not committed here yet. To use the SnapEDA model:

1. Open the source page in a browser.
2. Download the KiCad CAD model package.
3. Extract the KiCad footprint/symbol files.
4. Copy the extracted footprint into `Internet_Footprints.pretty/` or a new project-local `.pretty` library.
5. Update `fp-lib-table` and the schematic footprint field if the footprint name differs.

The current project instead uses online-downloaded KiCad official footprints for the headers, JST-SH connector, resistors, test point, and mounting holes.
